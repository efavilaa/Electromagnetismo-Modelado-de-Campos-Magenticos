# Modelado de Campos Magnéticos y Confinamiento de Partículas

Proyecto desarrollado para la materia **Modelación Computacional de Sistemas Electromagnéticos** (ITESM Campus Monterrey).

## Descripción

Este proyecto implementa en MATLAB la simulación de campos magnéticos generados por solenoides mediante la Ley de Biot-Savart y analiza el confinamiento de partículas cargadas utilizando la fuerza de Lorentz. Se estudia cómo diferentes parámetros geométricos y eléctricos afectan la estabilidad del confinamiento magnético.

## Características

* Cálculo numérico del campo magnético tridimensional de un solenoide.
* Visualización de perfiles longitudinales, topologías 3D y líneas de flujo.
* Simulación de trayectorias helicoidales de protones mediante Runge-Kutta de cuarto orden (RK4).
* Verificación de conservación de energía cinética.
* Análisis de estabilidad radial y confinamiento.
* Comparación de diferentes configuraciones:

  * Número de espiras (NL)
  * Corriente eléctrica (I)
  * Separación entre espiras (sz)

## Temas Físicos

* Ley de Biot-Savart
* Fuerza de Lorentz
* Radio de Larmor
* Confinamiento magnético
* Solenoides
* Introducción conceptual a reactores Tokamak

## Resultados

Las simulaciones muestran que el confinamiento mejora al aumentar el número de espiras y la corriente eléctrica, mientras que separaciones excesivas entre espiras generan regiones de campo débil que favorecen el escape de la partícula. Los resultados reproducen principios fundamentales utilizados en sistemas de confinamiento magnético tipo Tokamak.
